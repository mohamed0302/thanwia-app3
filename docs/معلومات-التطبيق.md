## 2. نظرة عامة على التطبيق

**الغرض:** تطبيق ويب/موبايل للمدرس والطلبة يتيح:
- عرض **فيديوهات الشرح** حسب صف الطالب
- متابعة **الدرجات والغياب** والملاحظات الطارئة
- عرض **الامتحانات** وروابطها
- **حجوزات الطلبة** (مواعيد الحصص)
- لوحة تحكم للمدرس لإدارة المحتوى وإرسال رسائل وإشعارات

**المنصات:** متصفح ويب، تطبيق أندرويد (عبر Capacitor)

## 5. المصادقة والأدوار

| الدور | طريقة الدخول | الصلاحيات |
|-------|--------------|-----------|
| **طالب** | كود الطالب | عرض الدرجات، الغياب، الامتحانات، الفيديوهات |
| **مدرس** | بريد + كلمة مرور | كامل الصلاحيات + لوحة الإدارة |
| **مساعد** | بريد + كلمة مرور | نفس المدرس |
| **زائر** | زر "الدخول كزائر" | محتوى محدود (فيديوهات عامة) |

**JWT:** صالح 7 أيام. يُخزّن في localStorage كمفتاح `finapp_token`.

## 6. مصادر البيانات

### 6.1 أولوية المصادر

1. **Firebase Realtime Database** — المصدر الرئيسي للدرجات، الغياب، الرسائل، الفيديوهات، الامتحانات
2. **Supabase** — بديل عند عدم توفر Firebase (RPC: get_student_messages، جدول exams)
3. **الخادم المحلي** — users، videos، bookings، grades في `data.json`
4. **بيانات تجريبية** — عند غياب السيرفر أو بيانات فارغة

### 6.2 بنية Firebase

```
students/
  {كود_الطالب}/
    meta/           # الاسم، الصف، إلخ
    grades/         # درجات الامتحانات { text, timestamp }
    absence/        # الغياب والحضور { text, timestamp }
    messages/       # تقارير وملاحظات طارئة { text, timestamp }
    fcmToken        # رمز الإشعارات

videos/
  {الصف}/           # فيديوهات حسب الصف

exams/
  {الصف}/           # امتحانات حسب الصف
```

## 7. واجهة برمجة التطبيقات (API)

### 7.1 عامة

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | `/api/auth/login` | تسجيل دخول المدرس (بريد + كلمة مرور) |

### 7.2 للمستخدم المسجّل

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| POST | `/api/register-fcm` | تسجيل رمز الجهاز لاستقبال الإشعارات |
| GET | `/api/exams?grade=` | جلب امتحانات صف معيّن |

### 7.3 إدارية (المدرس/المساعد)

| الطريقة | المسار | الوصف |
|---------|--------|-------|
| GET | `/api/admin/me` | بيانات الحساب |
| PUT | `/api/admin/me` | تحديث البريد، الاسم، كلمة المرور |
| GET | `/api/admin/videos?grade=` | جلب الفيديوهات |
| POST | `/api/admin/videos` | إضافة فيديو |
| DELETE | `/api/admin/videos/:id` | حذف فيديو |
| GET | `/api/admin/messages/:studentCode` | رسائل الطالب (درجات، غياب، ملاحظات) |
| POST | `/api/admin/messages/add` | إضافة رسالة + إرسال إشعار FCM |
| DELETE | `/api/admin/messages/:code/:type/:id` | حذف رسالة |
| GET | `/api/admin/exams?grade=` | جلب الامتحانات |
| POST | `/api/admin/exams` | إضافة امتحان |
| DELETE | `/api/admin/exams/:id` | حذف امتحان |

## 8. الميزات التفصيلية

### 8.1 الدرجات والغياب

- عرض **تقارير الامتحانات** بصيغة منظمة (اسم الامتحان، الصف، التاريخ، الدرجة المحققة، النسبة، الحالة، التقييم، نصائح)
- **تمييز كلمة حاضر/غائب** في رسائل الغياب والملاحظات
- **الدرجة المحققة** معروضة في صندوق بارز بألوان مميزة

### 8.2 الإشعارات

- طلب إذن الإشعارات من الطالب
- تسجيل رمز FCM في Firebase
- إرسال إشعار عند إضافة رسالة جديدة للطالب (عنوان + نص مختصر)

### 8.3 التصميم

- واجهة عربية RTL
- ألوان primary (تركواز) من Tailwind
- شريط سفلي للموبايل (BottomNav)
- بطاقات وظلال ناعمة
